# Туннельное движение

Сюрреалистичный 3D-шутер для браузера: пилотируйте корабль-коллектор внутри нестабильного туннеля, вращайтесь вокруг его оси, собирайте монеты, разрушайте препятствия выстрелами и уничтожайте бесформенных клякс и наблюдающие цели.

## Играть онлайн

Сайт опубликован через GitHub Pages: **https://karas-prog.github.io/tunnel-motion/**

## Запуск локально

Откройте `index.html` в современном браузере с поддержкой WebGL. Для стабильной работы ES-модулей рекомендован простой локальный сервер, например расширение Live Server в VS Code.

Проект использует Three.js через CDN, поэтому при запуске требуется доступ к интернету.

## Публикация через GitHub Pages

1. Откройте Settings → Pages в репозитории.
2. В блоке Build and deployment выберите Source: Deploy from a branch.
3. Укажите Branch: main и Folder: /(root).
4. Сохраните настройки — GitHub автоматически опубликует сайт после каждого коммита в main.

## Управление

- `A` / `←` — поворот вокруг оси против часовой стрелки
- `D` / `→` — поворот вокруг оси по часовой стрелке
- `Пробел` или клик — энергетический импульс
- `P` — пауза / продолжение
- `R` — рестарт после поражения

## Игровые объекты

- Корабль-коллектор — управляемый игроком аппарат в форме дельта-крыла; HUD-иконка внизу экрана визуально стреляет и вспыхивает кольцом при сборе монет.
- Монеты — вращающиеся золотые кольца; каждые 10 монет повышают уровень, увеличивают скорость и немного восстанавливает здоровье.
- Барьеры и многогранники — разрушаются как столкновением, так и выстрелами.
- Разрушаемые «глаза» — цели, требующие двух попаданий.
- Бесформенные кляксы — органические враги со случайной деформацией поверхности, требующие двух попаданий.

## Прогрессия

- Счётчик монет и текущий уровень отображаются в HUD.
- При достижении 10 монет показывается баннер нового уровня, растёт скорость полёта и восстанавливается часть здоровья.
