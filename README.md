# Туннельное движение

Сюрреалистичный 3D-шутер для браузера: пилотируйте корабль-коллектор внутри нестабильного туннеля, вращайтесь вокруг его оси, собирайте монеты, а корабль автоматически ведёт огонь и прокачивает оружие по мере роста уровня.

## Играть онлайн

Сайт опубликован через GitHub Pages: **https://karas-prog.github.io/tunnel-motion/**

## Запуск локально

Откройте `index.html` в современном браузере с поддержкой WebGL. Для стабильной работы ES-модулей рекомендован простой локальный сервер, например расширение Live Server в VS Code.

Проект использует Three.js через CDN, поэтому при запуске требуется доступ к интернету.

## Публикация через GitHub Pages

1. Откройте Settings → Pages в репозитории.
2. В блоке Build and deployment выберите Source: Deploy from a branch.
3. Укажите Branch: main и Folder: /(root).
4. Сохраните настройки — GitHub автоматически опубликует сайт после каждого коммита в main.

## Управление

- `A` / `←` — поворот вокруг оси против часовой стрелки
- `D` / `→` — поворот вокруг оси по часовой стрелке
- `Пробел` или клик — усиленный ручной залп поверх автоатаки
- `P` — пауза / продолжение
- `R` — рестарт после поражения

## Игровые объекты

- Корабль-коллектор — визуально закреплён у края кадра; ведёт автоматический огонь по ближайшим угрозам.
- Монеты — вращающиеся золотые кольца; каждые 10 монет повышают уровень, увеличивают скорость, восстанавливают здоровье и прокачивают оружие.
- Барьеры и многогранники — разрушаются как столкновением, так и выстрелами.
- Разрушаемые «глаза» и бесформенные кляксы — цели, требующие нескольких попаданий.

## Автоатака и прогрессия оружия

- Корабль стреляет автоматически, пока в туннеле есть «глаза» или кляксы — игроку не нужно постоянно жать пробел.
- Ручной выстрел (`Пробел`/клик) остаётся доступен как дополнительный залп с собственным кулдауном.
- С каждым уровнем оружие меняется по таблице:
  - Уровень 1 — одиночный выстрел, базовый урон.
  - Уровень 2 — ускоренная скорострельность.
  - Уровень 3 — двойной залп с небольшим разбросом.
  - Уровень 4 — увеличенный урон снаряда.
  - Уровень 5+ — тройной веерный залп и максимальная скорострельность.
